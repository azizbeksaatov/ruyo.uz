## 2. Ежедневный гороскоп

### Шаблон RU (t.me/ruyouz_ru)

```
🔮 Гороскоп на {дата} — {знак зодиака}

{текст гороскопа, 3–4 предложения}

{эмодзи знака} Читать полный гороскоп → ruyo.uz/ru/goroskop/{slug}

#гороскоп #{знак} #астрология #ruyo
```

### Шаблон UZ (t.me/ruyo_uz)

```
🔮 {sana} uchun munajjimlar bashorati — {burj nomi}

{bashorat matni, 3–4 gap}

{burj emoji} To'liq bashoratni o'qish → ruyo.uz/uz/goroskop/{slug}

#munajjimlar #{burj} #astrologiya #ruyo
```

**Эмодзи знаков:**
♈ Овен | ♉ Телец | ♊ Близнецы | ♋ Рак | ♌ Лев | ♍ Дева
♎ Весы | ♏ Скорпион | ♐ Стрелец | ♑ Козерог | ♒ Водолей | ♓ Рыбы

**Правила:**
- Публиковать все 12 знаков последовательно по неделям (не все сразу)
- Чередовать знаки: понедельник — Овен/Телец, вторник — Близнецы/Рак, и т.д.
- Текст: 2–4 предложения, позитивный тон, конкретные советы

## 3. Значение имён

### Шаблон RU

```
👤 Имя {Имя} — что оно означает?

✨ {краткое значение, 1 предложение}

📖 {развёрнутое значение, 2–3 предложения}

🔗 Полное значение имени → ruyo.uz/ru/imya/{slug}

#имя #{Имя} #значениеимени #ruyo
```

### Шаблон UZ

```
👤 {Ism} ismi — bu nima degani?

✨ {qisqacha ma'nosi, 1 gap}

📖 {batafsil ma'nosi, 2–3 gap}

🔗 To'liq ma'nosini ko'rish → ruyo.uz/uz/imya/{slug}

#ism #{Ism} #ismmаnosi #ruyo
```

**Выбор имён:**
- Приоритет: популярные узбекские и русские имена (топ-50)
- 1 имя в день, чередовать мужские/женские
- Не повторять имя в течение 2 месяцев

### Шаблон UZ

```
🌙 Tushda {narsa} ko'rish nima degani?

💭 {qisqacha ta'bir, 1–2 gap}

👩 Ayollar uchun: {1 gap}
👨 Erkaklar uchun: {1 gap}

#tushta #tushtabirnomasи #ruyo

**Выбор снов:**
- Приоритет: топ-30 популярных символов (змея, зубы, вода, огонь, деньги, свадьба...)
- 1 сон в день (4–5 раз в неделю, в пт/сб — тест вместо сонника)

### Шаблон UZ

```

{qiziqtiruvchi savol, 1 gap}

{N} savoldan iborat testni bajaring — natijangizni biling!

▶️ Testni boshlash → ruyo.uz/uz/test/{slug}

**Выбор тестов:**

- Ротация всех 19 тестов, повтор через 3 недели

## 7. Тон и стиль

| | Telegram | Instagram |
|---|---|---|
| Тон | Дружелюбный, чуть мистический | Визуальный, лёгкий |
| Длина | 80–150 слов | 50–80 слов |
| Эмодзи | 3–5 на пост | 5–8 на пост |
| CTA | «Читать полностью →» | «Ссылка в bio» |

**Нельзя:**
- Негативные предсказания без позитивного выхода
- Медицинские/финансовые советы
- Копирование чужого контента без ссылки

## 9. KPI (ежемесячно)

- Подписчики: +500 RU, +300 UZ в месяц
- Охват поста: ≥200 просмотров (Telegram)
- CTR (переходы на сайт): ≥5% от просмотров
- Лучший формат: отслеживать через utm-метки в ссылках

**UTM-шаблон:**
```
ruyo.uz/ru/sonnik/zmeya?utm_source=telegram&utm_medium=social&utm_campaign=sonnik
```
